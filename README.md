FutureDevAcademy — Backend API

Overview

FutureDevAcademy is a course management application with an ASP.NET Core Web API backend. It provides backend functionality for managing courses, users, categories, and student enrollments.

Technologies

C#

ASP.NET Core Web API

Entity Framework Core

SQL Server

JWT Authentication and Authorization

RESTful API architecture

Project Structure

Domain — Core entities and domain models.

Application — Application logic, DTOs, and service abstractions.

Infrastructure — Database access and repository implementations.

FutureDevAcademy — API entry point, controllers, configuration, and application startup.

Main Features

Course management.

Student and user management.

Category management.

Student enrollment functionality.

Authentication and authorization.

Database integration using Entity Framework Core
